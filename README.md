This repository accompanies the manuscript “Significant Ecological Reorganization of Planktonic Diatom Communities Across the Mid-Pleistocene Transition in the Okhotsk Sea” (Lo et al.). It contains:

data/: raw diatom counts, age model, and environmental proxies (SST, TOC, TN, TP, TIC, dinosterol) for core MD01-2414
R/: scripts for Hill-number diversity (iNEXT.beta3D), nMDS, IndVal, GAMM, RF, GBM, and MARS
output/: figures, tables, and model results (Figs. 2–11, Tables 1 and S1–S3)

Please cite the Zenodo archive (DOI:10.5281/zenodo.24334714) and the article.
